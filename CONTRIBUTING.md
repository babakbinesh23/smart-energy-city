# Contributing

Thank you for helping improve the open-source reference demo.

## Getting started

1. Open an issue to discuss substantial changes.
2. Fork the repository and create a branch such as `feature/solar-dashboard`.
3. Install dependencies: `npm install`.
4. Make one focused change, add or update relevant tests, and run `npm test` and `npm run build`.
5. Open a pull request with a description, screenshots for UI changes, and a link to the relevant issue.

## Contribution priorities

- Energy calculation examples with documented assumptions and unit tests
- Accessibility, mobile controls, RTL user experience, and localization
- Lightweight, reproducible Three.js scenes and asset optimization
- WebXR experiments with comfortable locomotion options
- Security, performance, and developer documentation

## Please do not include

- API keys, passwords, internal IP addresses, or private URLs
- Customer billing or personal information
- Licensed 3D models, commercial audio, company logos, or proprietary files without permission
- Unsupported financial claims or fabricated project adoption metrics

By contributing, you confirm you have the right to submit your work under the repository's MIT license.
