# Codex / AI contributor instructions

Scope: an educational, non-production Three.js reference demo.

1. Do not claim this repository contains full proprietary Smart Energy City source.
2. Before changes, inspect relevant code and tests; make narrow, reviewable commits.
3. Keep pure numerical calculations in `src/energy-model.js`.
4. Never add tokens, private credentials, personal data, or customer records.
5. Do not add proprietary or unlicensed media assets.
6. Preserve RTL usability, mobile accessibility, and clear unit labels.
7. Explain model assumptions and do not present simplified examples as real engineering results.
8. Run `npm test` and `npm run build` before requesting a review.
