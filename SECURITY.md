# Security Policy

This is an educational browser demo; it does not provide production energy management controls.

## Reporting a vulnerability

Do **not** post exploitable security details, leaked keys, credentials, or private data in public issues.
Use GitHub's **Report a vulnerability** / private security advisory feature, if enabled on this repository, or contact a maintainer privately.

Security reports should explain impact, affected versions, a safe reproduction, and suggested mitigation.
No response SLA is guaranteed at the project's current early stage.
