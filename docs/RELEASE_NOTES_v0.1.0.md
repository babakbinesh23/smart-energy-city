# Release v0.1.0 — First Public Reference (2026-11-21)

## Included

- Browser-based, right-to-left Persian interactive 3D city built with Three.js
- Procedural geometry for industrial energy, solar PV, household aggregation, efficiency, and storage
- Editable educational examples with clear units
- Pure energy-model functions and Node.js unit tests
- Contribution guidelines, code of conduct, security policy, and publication audit
- GitHub Actions checks and a GitHub Pages deployment workflow

## Supported

- Modern desktop and mobile browsers with WebGL support
- Node.js 20+ for development

## Not included

- The proprietary Smart Energy City WordPress production plugin v2.5.250
- Proprietary GLB media, voiceover, soundtrack, images, or branding assets
- Customer and visitor data, authentication, multiplayer, backend endpoints, or contracts

## Known limitations

- Simplified educational calculations only: not a billing, dispatch, planning, or settlement engine
- No persistent backend
- No complete browser automated test suite yet
- GitHub Pages needs to be enabled in repository settings before the live demo works

## Verification

CI runs `npm test` and `npm run build`. Passing results are visible under GitHub Actions. No claims are made about downloads, stars, external users, or production adoption of this public reference.
