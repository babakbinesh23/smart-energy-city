# هشدار امنیتی و راهنمای اصلاح ورود مدیر — برقتو 2.5.250

## مشکل کشف‌شده

در آرشیو اصلی ارسالی، تابع ورود مدیر در `multiplayer.php` از **رمز ثابت و ضعیف داخل کد** استفاده می‌کرد. Endpoint ورود برای کاربران غیرلاگین نیز در دسترس بود. مقدار رمز در این سند منتشر نمی‌شود.

## اصلاح کد GitHub

در نسخه منتشرشده عمومی، رمز ثابت حذف شده است. تابع ورود:
- یک حساب مدیر وردپرس با مجوز `manage_options` را می‌پذیرد؛ یا
- برای ورود با رمز مستقل، `password_verify` را روی هش تنظیم‌شده در `BARGHETO_CITY_ADMIN_PASSWORD_HASH` اجرا می‌کند؛
- اگر هش تنظیم نشده باشد و کاربر مدیر وردپرس نباشد، ورود رد می‌شود.

## اصلاح سایت فعال (الزامی)

**انتشار در GitHub هیچ تغییری در نصب وردپرس فعلی ایجاد نمی‌کند.**

1. از سایت و پایگاه‌داده بکاپ بگیر و اول در محیط Staging آزمایش کن.
2. کد `multiplayer.php` اصلاح‌شده را از این مخزن دریافت کن.
3. در صورت استفاده از رمز مستقل، یک رمز قوی جدید بساز؛ روی محیط مطمئن با PHP مقدار `password_hash(NEW_SECRET, PASSWORD_DEFAULT)` را تولید کن. مقدار رمز خام را منتشر نکن.
4. هش را فقط در فایل امن `wp-config.php` به شکل `define('BARGHETO_CITY_ADMIN_PASSWORD_HASH', 'HASH_VALUE');` ثبت کن.
5. فرآیند ورود مدیر، خروج، مدیریت نشست‌ها، API چندنفره و مهمان را آزمایش کن؛ ورود با رمز قبلی باید رد شود.
6. نشست‌های قبلی مدیر را منقضی کن. مجوزهای endpointها، nonce، آپلود فایل و داده‌های بازدیدکنندگان به بازبینی جداگانه نیاز دارند.

## وضعیت تأیید

- بررسی نحوی PHP و JavaScript انجام شده است.
- تست مستقل مرورگر یا تست امنیتی نفوذ برای نسخه واقعی انجام نشده است.
- سایت زنده در این گفتگو تغییر داده نشده است.

**این تغییر به‌تنهایی گواه ایمنی کامل سایت نیست.**
