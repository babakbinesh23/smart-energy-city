## Evidence limits

- The original archive contains notes and compiled runtime files. **A versioned TXT file is not equivalent to proof of deployment, a public release, or an independent user test.**
- The provided original plugin is WordPress-based, using PHP and prebuilt JavaScript; it also has Babylon.js office components.
- The private archive contains saved data and externally sourced media that may not be redistributed publicly.
- The maintainers of this public GitHub repository began publishing an independent educational reference in November 2026; these older product notes must not be dated as public open-source commits.
- The original 2.5.250 note explicitly says an actual headset test was not performed for its VR-audio changes. Do not claim that field validation occurred.

## How this contributes to responsible open-source work

These archived notes identify concrete engineering experience and candidate reusable topics, such as WebXR input arbitration, streaming assets, geometry culling, mobile quality adaptation, and accessible dialogue controls. Only code with clear release rights and no user data can become part of the public repository.
