# راهنمای مشارکت در توسعه

این مخزن برای توسعه‌دهندگان JavaScript، Three.js، UX و افراد علاقه‌مند به آموزش انرژی باز است.

1. ابتدا بخش [Issues](https://github.com/babakbinesh23/smart-energy-city/issues) را بررسی کن. برای تغییرات بزرگ، ابتدا یک Issue واقعی ایجاد کن.
2. مخزن را Fork و یک Branch جدا ایجاد کن.
3. وابستگی‌ها را با `npm install` نصب کن.
4. برای تغییرات محاسباتی در `src/energy-model.js` تست در `tests/` اضافه کن.
5. دستورات `npm test` و `npm run build` را اجرا کن.
6. یک Pull Request با توضیح تغییر، تأثیر و در صورت نیاز تصویر ارسال کن.

### خط‌قرمزها

- کلید API، اطلاعات کاربران، فایل‌های WordPress backup یا آدرس‌های خصوصی را وارد نکن.
- مدل/صدا/ویدیوهای دارای محدودیت مجوز را وارد نکن.
- نسخه نمایشی عمومی را نسخه کامل محصول صنعتی معرفی نکن.
- فرمول‌های آموزشی را بدون تعیین فرضیات و محدودیت‌ها مالی یا مهندسی جلوه نده.
