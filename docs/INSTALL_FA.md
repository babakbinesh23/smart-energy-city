# راهنمای نصب و اجرای نمونه عمومی (فارسی)

**این راهنما مربوط به نمونه مرجع متن‌باز است، نه افزونه تولیدی وردپرس نسخه 2.5.250.**

## پیش‌نیازها

- Node.js نسخه 20 یا جدیدتر
- Git و یک مرورگر با WebGL
- اینترنت برای اولین نصب وابستگی‌های npm

## اجرای محلی

```bash
git clone https://github.com/babakbinesh23/smart-energy-city.git
cd smart-energy-city
npm install
npm test
npm run dev
```

لینکی را که Vite در ترمینال می‌دهد در مرورگر باز کن (معمولاً http://localhost:5173/).

## ساخت نسخه استاتیک

```bash
npm run build
npm run preview
```

خروجی build داخل پوشه `dist/` قرار می‌گیرد. این خروجی برای دامنه فرعی GitHub Pages با مسیر `/smart-energy-city/` ساخته شده است. برای میزبانی در دامنه یا مسیر دیگری باید `base` در `vite.config.js` متناسب با آن تغییر کند.

## تعامل

- گردش دوربین با موس یا لمس
- Zoom با اسکرول موس
- انتخاب یکی از پنج بخش انرژی از پنل
- تغییر اسلایدرها و مشاهده محاسبات آموزشی

این پروژه فاقد احراز هویت، مدیریت کاربران، داده مشترکین، مدل‌های GLB شرکت و API وردپرس است. نباید از اعداد فرضی آن برای تصمیم مالی یا مهندسی استفاده کرد.
