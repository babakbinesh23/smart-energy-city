# Public release provenance and audit

The public repository is a small independent educational reference built with Three.js. It is **not** the full commercial Bargheto City WordPress plugin.

The original source package included company-owned code, personal visitor data, proprietary assets and potentially third-party licensed media. Those materials must **not** be published without a separate authorization and security/license review.

No production customer records, phone numbers, passwords, API keys, or internal IP addresses should enter this public repository.

The MIT license applies only to original files written for this open-source reference, not to trademarks, models, voiceovers or other company materials.

All numerical results are simplified instructional examples, not verified energy engineering or financial advice.
