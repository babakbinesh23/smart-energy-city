# Publication audit and scope

The author authorized publishing the original Smart Energy City source. A sanitized **code-only** snapshot of WordPress production v2.5.250 is available at [production/v2.5.250](../production/v2.5.250/README.md). The earlier standalone educational Three.js reference remains a separate component and is **not** the original game.

The original archive contained visitor records, backups, large proprietary/third-party media and some third-party license restrictions. Those items were excluded from this public snapshot. Do not add private customer data, passwords, API keys, internal network addresses, or unlicensed media.

**Important live-site security finding:** A fixed administrator password existed in the owner's original `multiplayer.php`; the public copy has been hardened, but **the running WordPress installation has not automatically received that patch**. See [Security hardening](SECURITY_HARDENING_FA.md).

The source-only snapshot contains distributed frontend JavaScript and not necessarily its full original editable development source tree and reproducible lockfile. WordPress and separate media are required to use the original game. The MIT license governs owner-authored published code only; third-party code retains its own notices. No security penetration test was completed.

Educational energy figures in the independent reference are illustrative and are not verified engineering or settlement figures.
