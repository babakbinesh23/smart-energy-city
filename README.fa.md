# شهر هوشمند انرژی برقتو — پروژه اصلی و مرجع متن‌باز

این مخزن شامل **دو بخش متفاوت** است. آن‌ها را نباید با هم اشتباه گرفت.

1. **[کد واقعی شهر هوشمند انرژی نسخه 2.5.250](production/v2.5.250/README.fa.md):** کدهای افزونه وردپرس، ماژول‌های PHP، خروجی JavaScript و بخش Babylon.js. این بخش **بدون** داده‌های کاربران، بکاپ‌ها، مدل‌ها، رسانه‌ها و تنظیمات خصوصی منتشر شده است. سه فایل بزرگ باید با ابزار درج‌شده در مخزن بازسازی شوند. این بسته به‌تنهایی یک نصب کامل و قابل اجرای مستقل نیست.
2. **[نمونه ساده آموزشی Three.js](https://babakbinesh23.github.io/smart-energy-city/reference/):** یک دموی مستقل با هندسه ساده و محاسبه‌های آموزشی. این نمونه **نمای واقعی بازی اصلی نیست**.

## تست نمونه مستقل

```bash
npm install
npm test
npm run build
npm run dev
```

این دستورات نسخه آموزشی را اجرا می‌کنند، نه افزونه وردپرسی اصلی.

## امنیت و نگهداری

- رمز ثابت مدیریت از **کپی منتشرشده** حذف شده است، ولی این کار **هیچ تغییری در سایت وردپرسی زنده ایجاد نکرده است**. [راهنمای ایمن‌سازی سایت اصلی](docs/SECURITY_HARDENING_FA.md)
- گزارش‌های سابقه توسعه محصول به صورت مستندات ثبت شده‌اند، نه Commitهای قدیمی GitHub.
- فعالیت عمومی از تاریخ ایجاد مخزن آغاز شده و سابقه مشارکت اشخاص ثالث به‌صورت ساختگی اعلام نمی‌شود.
- اسکریپت‌های تست/انتشار از GitHub Actions اجرا می‌شوند. [وضعیت انتشار](https://github.com/babakbinesh23/smart-energy-city/actions)
