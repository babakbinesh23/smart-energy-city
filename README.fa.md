# شهر هوشمند انرژی — نسخه مرجع متن‌باز

این مخزن شامل یک **نمونه سبک و قابل اجرای آموزشی با Three.js** است که برای معرفی عمومی پروژه شهر هوشمند انرژی آماده شده است.

**مهم:** این مخزن حاوی سورس کامل افزونه تولیدی وردپرس نسخه ۲.۵.۲۵۰ نیست. فایل کامل ارسالی کاربر شامل اطلاعات بازدیدکنندگان، بکاپ‌های رسانه و دارایی‌هایی با حقوق نشر متفاوت بود و نباید بدون پاکسازی منتشر شود.

## امکانات نمونه عمومی

- شهر سه‌بعدی قابل چرخش، انتخاب بخش‌ها و پنل راست‌چین
- محاسبه آموزشی تولید خورشیدی و تجمیع تولید خانگی
- مقایسه مصرف موتور، ذخیره‌سازی انرژی و پیشنهادهای فرضی تأمین برق
- کد جاوااسکریپت، تست خودکار و مستندات مشارکت

## اجرای محلی

```bash
npm install
npm run dev
```

برای اجرای تست: `npm test` و برای ساخت بسته وب: `npm run build`.

## تفاوت با پروژه اصلی

برنامه اصلی برقتو افزونه وردپرس، محتوای سه‌بعدی GLB، بخش VR و سامانه آنلاین دارد. نمونه عمومی صرفاً مفاهیم آموزشی و بخشی از قابلیت‌های گرافیکی را به شکل مستقل نمایش می‌دهد. فایل‌های اصلی شرکت، اطلاعات کاربران، مدل‌ها و صداهای نامطمئن از نظر مجوز **در این مخزن منتشر نشده‌اند**.
