Reproduction: install this folder's package.json dependencies, put the exact original supplied GLB
at source-transformer.glb, install Playwright Chromium, then npm run export and npm run compress.
Set CHROMIUM_PATH only when using a custom Chromium installation. Export renders three views and
writes upgraded-raw.glb; compression writes final.glb. The original input is not duplicated inside
the plugin ZIP. For game development, restore the shipped font with restore-assets.mjs and copy
all existing server models plus the new GLB under src/assets/models/; audio belongs in src/assets/audio/.
