# سورس واقعی شهر هوشمند انرژی برقتو — نسخه 2.5.250

این پوشه کدهای واقعی افزونه وردپرس و بازی برقتو را دارد؛ با **نمونه ساده آموزشی** داخل پوشه `src` تفاوت دارد.

## فایل‌های موجود

- کدهای PHP افزونه، ورود کاربران، شبکه چندنفره، ویرایشگر و مدیریت رسانه
- JavaScript واقعیِ نسخه توزیع‌شده Three.js، فایل‌های دفتر Babylon.js و WebXR
- ابزارهای آزمایش و فایل‌های انتساب مجوزها

## محدودیت‌ها

اطلاعات بازدیدکنندگان، مدل‌های GLB، صداها، ویدئو، تصاویر، فونت‌ها و تنظیمات خصوصی در GitHub قرار نگرفته‌اند. بنابراین **این پوشه به‌تنهایی نسخه کامل قابل اجرای سایت نیست** و برای اجرای اصلی به وردپرس و رسانه‌های مجاز نیاز دارد.

بخش اصلی فرانت‌اند در ZIP اولیه به‌صورت فایل آماده/توزیع‌شده بود؛ سورس توسعه مستقلِ قابل Build همراه با Lockfile در فایل دریافتی نبود.

## بازسازی سه فایل بزرگ

از فولدر اصلی مخزن، روی سیستم دارای Node.js دستور زیر را اجرا کن:

```bash
node production/v2.5.250/restore-split-files.mjs
```

این دستور بخش‌های سه فایل بزرگ را به هم وصل می‌کند و پیش از ذخیره، هش SHA-256 را بررسی می‌کند. مسیر فایل‌های بازسازی‌شده:

- `game/dist/assets/index-2.5.250.js`
- `office/source-v22.html`
- `office/xr-babylon-8.46.2.js`

## امنیت

در سورس ارسالی، رمز مدیر به‌صورت ثابت داخل `multiplayer.php` قرار داشت. در نسخه GitHub این مورد حذف شده است. ورود مستقل فقط با هش رمز تعریف‌شده در `wp-config.php` کار می‌کند، یا با ورود مدیر معتبر وردپرس.

**تغییر فایل GitHub سایت فعلی را اصلاح نمی‌کند.** راهنما: [رفع مشکل امنیتی مدیر](../../docs/SECURITY_HARDENING_FA.md).
